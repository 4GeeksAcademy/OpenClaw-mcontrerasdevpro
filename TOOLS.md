# TOOLS.md - Configuración de Herramientas Conocidas

## Servicios Disponibles a través de Zapier
- **Gmail:** Usar para redactar borradores automáticos. Convención: guardar siempre en borradores antes de enviar.
- **Google Calendar:** Usar para agendar bloques de tiempo de estudio. Calendario por defecto: Principal.
- **Google Tasks:** Usar para registrar tareas del curso de AI Engineering.
- **Google Drive / Docs:** Usar para almacenar diarios de aprendizaje y notas de clase. Carpeta por defecto: "OpenClaw_Workspace".
- **Telegram:** Canal principal de comunicación móvil para recibir alertas y resúmenes diarios de GitHub.
